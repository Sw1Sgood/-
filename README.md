# Девелопер: от новичка к проектному мышлению

Персональная учебная платформа по девелопменту недвижимости: курс на 16 недель (8–9 часов в неделю) со сквозным учебным проектом —
многоквартирным жилым домом. Это не сайт с текстами и не чат с ИИ, а рабочая учебная система: программа по неделям,
практические задания с критериями, проектное досье, журнал источников, навыки и учёт времени.

Приложение работает **локально в браузере**: без сервера, без регистрации, без API-ключей и платных сервисов.

> Курс не обещает, что за 16 недель вы станете готовым девелопером. Цель — базовые навыки первого уровня, портфолио учебного
> проекта и понимание, что нужно проверять у профильных специалистов. Материалы не являются юридической, градостроительной,
> инженерной или инвестиционной консультацией.

## Запуск

Нужен [Node.js](https://nodejs.org/) версии 20 или новее.

```bash
npm install      # один раз
npm run dev      # режим разработки: откройте адрес из консоли (обычно http://localhost:5173)
```

### Сборка для постоянного использования

```bash
npm run build    # готовое приложение появится в папке dist/
npm run preview  # посмотреть собранную версию локально
```

Папку `dist/` можно выложить на любой статический хостинг (GitHub Pages, Netlify и т. п.) или в подпапку сайта — адреса
относительные, навигация через `#/…`, настройка сервера не нужна. Открыть `dist/index.html` двойным щелчком не получится:
браузеры не загружают модули со схемы `file://`, нужен любой локальный веб-сервер (например, `npm run preview`).

### Проверки

```bash
npm test         # юнит-тесты (содержание курса, резервная копия, прогресс, хранилище)
npm run build    # проверка типов TypeScript и сборка
npm run e2e      # сквозная проверка в браузере (после build); путь к Chromium можно задать в CHROMIUM_PATH
```

Сквозная проверка проходит ключевой сценарий: урок → заметка → задание → принятие → сессия → бюджет в досье →
перезагрузка → экспорт копии → удаление данных → отказ на некорректном файле → импорт → данные восстановлены. Затем
открывает все разделы на экране шириной 375 px и проверяет, что нет горизонтальной прокрутки и ошибок JavaScript.

## Резервное копирование и восстановление

Данные хранятся **только в этом браузере на этом устройстве**. Они пропадут, если очистить данные сайта, и не появятся
в другом браузере сами по себе.

- **Сохранить копию:** «Настройки» → «Скачать резервную копию (JSON)». Делайте это регулярно, например раз в неделю.
- **Восстановить:** «Настройки» → «Восстановить из файла…». Приложение проверит формат и покажет, что в копии (уроки, задания,
  сессии, навыки, досье), и только после подтверждения заменит текущие данные. Если файл повреждён или чужой, данные
  не меняются, а на экране появится список ошибок.
- **Перенос на другое устройство:** скачайте копию на одном устройстве и восстановите её на другом.
- **Артефакты для портфолио:** в «Настройках» есть выгрузка досье и заданий в Markdown, сессий и таблиц досье (бюджет, риски,
  конкуренты, источники и др.) в CSV. CSV рассчитан на Excel и LibreOffice Calc с русской локалью: разделитель «;», UTF-8 с BOM.

## Что умеет приложение

| Раздел | Возможности |
|---|---|
| **Главная** | «Продолжить обучение» — ближайший полезный шаг; прогресс (принятые практики отдельно от прочитанных уроков); план и факт времени за неделю; таймер сессии и ручной ввод; ближайшие и перенесённые задачи; сводка досье; последние заметки; спокойное предложение пересчитать график при отставании; напоминание об обзоре модуля |
| **Учебный план** | 4 модуля × 4 недели; статусы «Не начата / В процессе / Ожидает проверки / Завершена»; недели не блокируются |
| **Урок** | Цель, связь с проектом, объяснение, словарь (с английскими терминами), «Что важно понять», 3–7 вопросов самопроверки с полем ответа и подсказкой, материалы с задачей «что найти», заметки и «Что осталось непонятно»; кнопки «Начать», «Сохранить заметку», «Отметить изученным», «Перенести», «Сообщить: ссылка не работает» |
| **Задание** | Зачем, ситуация, входные данные, где искать, 4–8 шагов, формат результата; ответ полями, таблицей и ссылкой на файл; чек-лист критериев; частые ошибки; рефлексия; рубрика на 100 баллов для аналитических работ; статусы «Не начато → В процессе → Готово к проверке → Нужно доработать / Принято» |
| **Проект** | 12 разделов досье по ТЗ: обзор, участок, градостроительные сведения, рынок, концепция, бюджет, доходы, финмодель, график, риски, решение, журнал источников. У каждого поля статус «Подтверждено / Допущение / Гипотеза / Нужно уточнить». Таблицы с итогами и вычисляемыми колонками (выручка, прибыль, маржа, оценка риска) |
| **Навыки** | 9 навыков, шкала 0–3; оценка выше нуля требует ссылки на артефакт: задание, заметки или раздел досье; история оценок |
| **Сессии** | Журнал (дата, длительность, тема, сделанное, непонятное, следующий шаг) с редактированием и удалением; суммы по календарным неделям и неделям курса; CSV |
| **Материалы** | Источники с пометкой «что искать», статусом и датой проверки ссылки; фильтры; отметка неработающих ссылок; свои материалы |
| **Итоги и обзоры** | Итоги недели (что получилось, что трудно, уверенность 1–5, что повторить); обзор модуля раз в 4 недели с автоматическим списком пробелов |

## Архитектура и выбор технологий

- **TypeScript + React + Vite + Tailwind CSS.** Стек из ТЗ: типизация ловит ошибки в содержании и данных, Vite быстро
  собирает, Tailwind даёт единый спокойный стиль без отдельного дизайн-фреймворка. Светлая и тёмная тема переключаются по
  настройке системы.
- **Без backend.** Для одного пользователя он не нужен, а без него нет хостинга, аккаунтов и утечек данных.
- **IndexedDB** вместо localStorage. Она асинхронна и не блокирует интерфейс, не ограничена ~5 МБ и лучше переживает
  очистку «лёгких» данных сайта. Всё состояние пользователя хранится одним документом: запись атомарна, а резервная копия —
  это просто этот документ с версией формата. Приложение также просит браузер не удалять данные при нехватке места
  (`navigator.storage.persist`). Сохранение автоматическое, с задержкой 0,4 с; статус («Сохранение… / Сохранено / Не
  сохранено») виден в шапке.
- **HashRouter** — чтобы собранное приложение работало из любой папки и на любом статическом хостинге.
- **Строгий импорт.** При загрузке и импорте данные проходят проверку (`src/store/backup.ts`): неверные типы и значения дают
  список ошибок с путём к полю, неизвестные поля отбрасываются, отсутствующие заполняются значениями по умолчанию. Есть
  поле `schemaVersion` для будущих миграций.
- **Без сторонних библиотек состояния и форм** — их заменяет небольшой провайдер (`src/store/StoreContext.tsx`). Зависимостей
  во время работы три: React, React DOM и React Router.

### Структура

```
src/
  content/            содержание курса — редактируется без изменения интерфейса
    course.ts         курс и модули
    weeks/module*.ts  16 недель: уроки, термины, вопросы, задания
    resources.ts      источники и статус их проверки
    skills.ts         навыки и описания уровней 0–3
    dossier.ts        разделы досье: поля и таблицы
    rubric.ts         рубрика на 100 баллов
  store/              данные пользователя: типы, IndexedDB, резервная копия, провайдер
  lib/                расчёты прогресса, даты, числа, экспорт Markdown/CSV
  components/         общие элементы интерфейса
  pages/              экраны
  test/               юнит-тесты
scripts/e2e.mjs       сквозная проверка в браузере
```

### Как изменить программу

Всё содержание лежит в `src/content/`. Чтобы поправить урок, добавить вопрос, заменить задание или источник, отредактируйте
соответствующий файл. Интерфейс подстроится сам. `npm test` проверяет целостность содержания: 16 недель по порядку,
уникальные идентификаторы, 3–7 вопросов в уроке, 4–8 шагов в задании, отсутствие ссылок на несуществующие ресурсы. Если
переименовать идентификатор урока или задания, прогресс по нему в уже сохранённых данных перестанет отображаться, поэтому
идентификаторы лучше не менять.

## Принятые допущения

ТЗ разрешает выбрать простое решение там, где детали не заданы. Выбор такой:

1. **В каждой неделе один урок и одно основное практическое задание.** Время недели складывается из урока с материалами
   (≈2–2,5 ч), задания (≈5–6 ч) и итогов недели.
2. **Неделя считается завершённой**, когда урок изучен *и* задание принято. Прочитанный урок без принятой практики оставляет
   неделю «В процессе»: прочитанное не равно освоенному.
3. **Принятие задания — самопроверка.** Вводные задания (недели 1–2) принимаются, когда отмечены все критерии чек-листа.
   Аналитические — когда заполнены все пять пунктов рубрики и сумма не меньше 85 баллов. Это учебный порог, а не экспертиза.
4. **Текущая неделя** — первая незавершённая по прогрессу. **Плановая неделя** считается по календарю от даты начала курса.
   При отставании на две недели и больше главная мягко предлагает пересчитать график, то есть сдвинуть дату начала. Прогресс
   при этом не меняется.
5. **Время за неделю** на главной считается по календарной неделе с понедельника по воскресенье. В разделе «Сессии» есть ещё
   разбивка по неделям курса.
6. **Обзор модуля** предлагается, когда завершены все его недели или когда календарь ушёл дальше последней недели модуля.
7. **Файлы не хранятся в приложении** — только ссылка или путь к ним. Это сохраняет копию маленькой, а таблицы и
   презентации остаются в привычных программах.
8. **Финансовая модель по периодам ведётся в табличном редакторе.** ТЗ предлагает Excel или Calc. В досье хранятся сводка
   сценариев, ключевые показатели и ссылка на файл.

## Достоверность содержания

- Объяснения написаны своими словами и коротко; чужие учебные материалы не копируются, вместо этого даются ссылки на
  оригиналы.
- Правовые темы изложены общими формулировками со ссылкой на первоисточник и пометкой сверить актуальную редакцию.
  Конкретные сроки процедур и цифры, которые нельзя проверить, не приводятся.
- Все учебные числа помечены как условные.
- **Ссылки проверены 21.10.2026 из среды разработки.** Статус «Ссылка открывалась» стоит только у страниц, которые
  открылись и чей заголовок совпал с описанием: НИУ ВШЭ, НИУ МГСУ, Градостроительный и Земельный кодексы и 214-ФЗ
  в КонсультантПлюс, страница ключевой ставки Банка России. Государственные порталы (Росреестр, НСПД, pravo.gov.ru,
  Росстат, Наш.дом.рф) из среды разработки были недоступны, поэтому помечены «Не проверено» — проверьте их сами.
  Бесплатность и условия доступа нигде не заявлены, если не подтверждены.

## Ограничения

- Один пользователь на одно устройство и один браузер. Синхронизации нет, перенос — через резервную копию.
- Приватный режим браузера может не сохранять данные между сеансами.
- Приложение не проверяет ссылки автоматически, не подключается к реестрам и картам и не делает выводов о законности
  строительства. Это намеренно: сведения об участке проверяются по первоисточникам и у специалистов.
- Нет ИИ-проверки: обратная связь строится на чек-листах и рубрике.

## Развитие (после MVP)

- Экспорт финансовой модели в XLSX; графики денежного потока и чувствительности по введённым данным.
- PWA — установка на главный экран и работа офлайн без сервера.
- Проверка доступности ссылок, если появится технически честный способ.
- Опциональный ИИ для объяснения терминов и критики черновиков — только после оценки стоимости и конфиденциальности,
  с пометкой «предварительная обратная связь».
- Безопасная синхронизация между устройствами.
- Продолжение курса: коммерческая недвижимость, реконструкция, управление активами, инвестиционный анализ.

## Демонстрационный сценарий (5 минут)

1. `npm run dev`, открыть приложение. Главная предлагает «Начать урок» недели 1.
2. Открыть урок, ответить на вопрос, раскрыть подсказку, написать заметку, нажать «Сохранить заметку», затем
   «Отметить изученным».
3. Вернуться на главную — следующим шагом стало задание. Заполнить поля, отметить критерии, нажать «Готово к проверке»,
   затем «Принять». В прогрессе появится «Практики приняты: 1 / 16».
4. Нажать «Начать учебную сессию», через минуту — «Завершить и записать». Время появится на главной и в «Сессиях».
5. «Проект» → «Бюджет»: добавить строку «СМР — 500 000 000», выбрать статус «Допущение». Итог посчитается сам.
6. «Навыки» → «Роли участников» → «Оценить навык» → уровень 1 → артефакт «Нед. 1: Схема участников…».
7. «Настройки» → «Скачать резервную копию» → «Удалить все данные» → «Восстановить из файла…». Всё вернулось.
8. Открыть приложение на телефоне или сузить окно до 375 px: меню сворачивается, таблицы прокручиваются внутри своей рамки.
